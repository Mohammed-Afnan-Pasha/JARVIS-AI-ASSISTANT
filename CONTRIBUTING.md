# Contributing to JARVIS

Thank you for your interest in contributing to JARVIS!

## Contribution Guidelines

1. Keep code clean, readable and organized.
2. Use meaningful names for files, functions and variables.
3. Explain significant changes in your pull requests.
4. Test your changes before submitting them.
5. Never upload API keys, passwords or private credentials.
6. Do not introduce automation that performs sensitive actions without appropriate user approval.

## Reporting Issues

When reporting an issue, include:

- A clear description of the problem.
- Steps to reproduce it.
- Expected behaviour.
- Actual behaviour.

## Feature Suggestions

Feature suggestions are welcome. Please explain the purpose of the feature and how it could improve JARVIS.

Thank you for helping improve JARVIS!
